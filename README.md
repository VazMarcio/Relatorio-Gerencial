# 📊 Relatório Interativo Power BI - Sample Financials

Este projeto foi desenvolvido como parte do desafio prático da DIO para aprimorar habilidades em Power BI e construir um portfólio de destaque. Utilizando o conjunto de dados "Sample Financials", o objetivo foi criar um relatório interativo, visualmente atrativo e funcional, com foco em navegação, segmentação e análise de indicadores financeiros.

---

## 🚀 Objetivos do Projeto

- Criar um relatório com **layout profissional e intuitivo**
- Utilizar **botões de navegação** para facilitar a experiência do usuário
- Aplicar **segmentadores de dados** com imagens associadas
- Permitir **interação dinâmica** entre visuais e indicadores
- Publicar o relatório no **Power BI Service** para acesso online

---

## 🧠 Conceitos Aplicados

- Modelagem de dados no Power BI
- Criação de páginas com navegação personalizada
- Segmentação por produto, região e período
- Métricas de desempenho: Receita, Lucro, Margem, etc.
- Visualizações: gráficos de barras, linhas, mapas e cartões

---

## 📚 O que aprendi com esse projeto

Este projeto foi uma excelente oportunidade para consolidar e expandir meus conhecimentos em Power BI e visualização de dados. Ao longo do desenvolvimento, aprendi e pratiquei os seguintes conceitos:

- ✅ **Modelagem de dados eficiente**: aprimorei minha capacidade de organizar e relacionar tabelas, garantindo uma base sólida para as análises.
- 🎨 **Design de dashboards interativos**: explorei o uso de botões, segmentadores com imagens e bookmarks para criar uma experiência de navegação fluida e intuitiva.
- 📊 **Criação de visuais impactantes**: utilizei diferentes tipos de gráficos (barras, linhas, cartões, mapas) para representar os dados de forma clara e objetiva.
- 🧠 **Análise de indicadores financeiros**: desenvolvi KPIs como Receita, Lucro e Margem, entendendo melhor como esses indicadores se relacionam com o desempenho do negócio.
- ☁️ **Publicação no Power BI Service**: aprendi a publicar e compartilhar relatórios online, facilitando o acesso e a colaboração.
- 🔁 **Iteração e melhoria contínua**: testei diferentes abordagens de layout e interatividade, buscando sempre a melhor experiência para o usuário final.

Este projeto não apenas reforçou minha base técnica, como também me ajudou a desenvolver um olhar mais crítico e estratégico sobre a apresentação de dados.
